# Gausalja Tharmarajah — Personal Website

Built with HTML, CSS and JavaScript.

## In VS Code
Open this folder, then open `index.html` in a browser. For live preview, install the VS Code extension **Live Server**.

## Before publishing
1. Put your VALUZ screenshots in `images/`.
2. Put your CV at `assets/CV-Gausalja-Tharmarajah.pdf`.
3. Replace the LinkedIn URL in `index.html`.

## GitHub Pages
Create a repository named `YOUR_GITHUB_USERNAME.github.io`, upload these files to `main`, then go to Settings → Pages → Deploy from a branch → `main` / `root`.
